# LEO Cars — Luxury Redesign

This is a static GitHub Pages-ready redesign for LEO Cars.

## Files
- `index.html` — page structure and content
- `styles.css` — luxury black/gold design
- `script.js` — mobile navigation and active-section highlighting
- `assets/leo-logo.png` — supplied LEO logo

## How to use
1. Upload/replace these files in your `leo-cars` GitHub repository.
2. Keep the `assets` folder in the same directory as `index.html`.
3. GitHub Pages should publish the updated site automatically.
4. Replace the three example vehicle cards with your actual inventory.

## Important
The vehicle photographs use external Unsplash image URLs as visual placeholders. Replace them with your own car photos for the final production site.
