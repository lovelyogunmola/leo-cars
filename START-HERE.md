# LEO Imported Cars: how to put this on your website

## 1. Unzip
Open the zip on your phone (Files app) or PC and extract it.

## 2. Upload to GitHub
Open github.com, go to your `leo-cars` repo.
- Main folder: tap Add file > Upload files. Upload `index.html`, `admin.html`, `cars.json`, `preview.jpg`. Commit changes.
- Folder `images`: open the `images` folder in GitHub first, then Add file > Upload files, select everything inside `images`. Commit.
- Folder `videos`: same, open `videos` in GitHub first, upload everything from `videos`.
- Folder `logos` (optional, only for keeping old logo styles).
Tip: on a computer you can drag the whole folder in one go. Wait about 1 minute, then open your site.

## 3. Your logo files (folder LOGO)
- logo.svg / logo.png: main logo (use for printing, banners, signs)
- icon-512.png / icon.svg: square icon (WhatsApp profile picture, Instagram, Facebook)
- whatsapp-preview.jpg: picture that shows when you share your link

## 4. Update cars from your phone
Open yoursite/admin.html and log in with your GitHub token. See HOW-TO-UPDATE.md.
